# 37 CFR 1.121 listing rules (bundled)

- Status identifiers: (Original), (Currently Amended), (Canceled), (Withdrawn),
  (New), (Previously Presented), (Withdrawn - Currently Amended).
- The server applies underline/strike. The model supplies full proposed text.
- Canceled claims have no text. Withdrawn claims remain in the listing.
- Election/restriction: non-elected claims are withdrawn, not canceled, unless
  the attorney explicitly cancels.
- Listing identity includes the format profile; a house-format change is a
  different artifact.
